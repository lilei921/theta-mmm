# 行业周期与估值框架

## 两个独立问题

1. **基本面方向**：未来 6–12 个月的供需缺口、订单和盈利预测是在改善还是恶化？
2. **预期定价**：当前股价已反映多少乐观/悲观预期？

| 景气预期 | 估值/预期未充分反映 | 估值/预期已充分反映 |
| --- | --- | --- |
| 改善 | 优先研究拐点与盈利上修 | 检验能否持续超预期 |
| 恶化 | 等待领先指标证伪悲观情景 | 警惕利润与估值双重压缩 |

## Bear / Base / Bull 必须显式落到驱动变量

- **Bear**：具体的需求、供给、价格、订单执行、成本、折现率不利假设。
- **Base**：中周期/更可能的经营路径，区分管理层目标与经验证的执行能力。
- **Bull**：超预期但有触发条件和可观测指标的情景。
- 每个情景都要输出盈利敏感性、合理价值区间、证伪条件；避免仅给三个任意 P/E 倍数。
- 估值更新需区分：盈利预测变化、估值倍数变化、净债务/股本变化、外汇变化。

## 不同赛道优先估值方法

| 赛道 | 适宜方法 | 主要注意 |
| --- | --- | --- |
| VLCC / 油轮 | 中周期 TCE 情景、DCF、NAV | Spot/TC 敞口、船龄、租入船、折旧和二手船价格 |
| 黄金/铜/铝 | 长期商品中枢 × 成本曲线、DCF、NAV | 资源储量、税费、资本开支、净负债 |
| CXO | DCF、Forward P/E、EV/EBITDA / 分部估值 | Backlog 可执行性、项目阶段、利用率、海外风险 |
| 创新药 | rNPV + 商业化产品 DCF + 净现金 | PoS（成功概率）、峰值销售、BD 权益结构 |
| 银行 | P/B-ROE、股息折现、盈利情景 | NIM、资产质量、资本充足率 |
| 平台/消费 | DCF、正常化利润及现金流估值 | 竞争、获客成本、渠道库存及变现率 |

**股价可能在利润改善前上涨，也可能在业绩最好时见顶**。估值研究应追踪的是未来假设与市场预期的差额，而不是只看当期财报同比。
