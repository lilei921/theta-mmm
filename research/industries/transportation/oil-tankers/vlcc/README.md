# VLCC · 吨海里、有效运力、TCE 与船舶资产

> industry_id: vlcc | 模型：capacity-cycle | 建档：2026-10-13。以下是研究方法，不表示当前运价或景气度。

## 盈利函数

```text
原油海运量 × 平均运输距离 = 吨海里需求
全球VLCC船队 + 新船交付 - 拆船 - 不可用运力 = 有效运力（简化）
吨海里需求 / 有效运力 + 即期货盘/船位分布 → TCE
实际TCE × 自有/租入船可用营运天数 → 航次收益
收益 - 船舶OPEX - 租船/融资/总部成本 - 折旧 → 利润和FCF
中周期TCE + 二手船价值 + 净负债 → NAV与股票合理价值
```

## 五个优先指标

| 层级 | 指标 | 投资含义 |
| --- | --- | --- |
| L1 | 未来 2–3 年 VLCC Orderbook/Fleet、交付/拆解/船龄 | 中期运力供给 |
| L1 | 全球原油吨海里及主要贸易流向 | 不同于仅看全球原油需求/海运吨数 |
| L1 | 即期货盘、可用船位、Fixtures、港口等待 | 未来数周运价压力 |
| L2 | TD3C、TD15、TD22 航线 TCE 与滚动均值 | 当前航次收益，领先季度实现 TCE |
| L2 | 五年船龄 VLCC 二手船价格 | 市场对长期运费、资产与供需的预期 |

指标口径、来源和限制见 [indicators.yaml](indicators.yaml)。BDTI 总指数不能代替 VLCC 航线 TCE。

## 周期与情景

- **Bear**：油运吨海里疲弱或有效供给增长更快，TCE 中枢下降。
- **Base**：运力与吨海里增速大致平衡，采用可持续的中周期 TCE 和运营天数。
- **Bull**：长航线需求扩张、供给受约束，可用运力紧张，TCE 及船价上行。

**估值方法**：中周期 TCE 敏感性 + DCF/NAV；当期利润 P/E 仅作交叉验证。TCE 每增加 1 万美元/天、假设 300 营运天，则每船年航次收益约增加 300 万美元（未扣除间接成本、租船结构影响；仅敏感性算例）。

## A/H 公司映射提醒

- 中远海能、招商轮船：需要分别估算实际 VLCC 自有/租入、即期/期租敞口，以及 LNG 等其他业务。
- 招商南油：主要是成品油/化学品油轮研究对象，**不能直接当作 VLCC 标的**。
- 历史讨论过以上公司不代表它们已被确认为当前独立长期跟踪，见 [历史研究索引](../../../../companies/archive/historical-research-index.md)。

## 证伪清单

订单簿集中交付、拆船不及预期、航线缩短、原油出口变化、市场船位紧张仅属阶段性扰动。关注季节性和地缘事件带来的短期跳升，避免用单周现货运价直接永久上调长期 TCE 中枢。
