# 公司研究与跟踪状态

**唯一状态来源**：[watchlist.yaml](watchlist.yaml)。

- [active](active/README.md)：用户明确持续/长期跟踪的公司。分 `core` 与 `focused`，不代表实际持仓。
- [archive](archive/README.md)：历史研究/阶段性讨论记录；只有明确停止长期跟踪的公司才能标为 `inactive`。
- `related`：已跟踪公司的重要子公司/关联公司，先跟随母公司跟踪，不擅自升级。

一个公司一个主档案；A/H 股票代码放证券列表，不拆分成两个公司。行业研究只引用公司主档案，不复制相互矛盾的财务预测。
